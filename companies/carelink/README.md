# CareLink

Hospital (patient portal). Patients book appointments, read their records and download reports. nginx checks every session with the auth service (auth_request).

| | |
|---|---|
| Language | python (`companies/runtime/python`) |
| Gateway | `web-gateway`, configured as nginx (not traced) |
| Login | bearer token |
| Public entry | `portal.carelink.example`, TLS |
| Service mesh mTLS | no |
| OpenAPI | 3.1.0 at `/openapi.json` |
| Outside APIs | none |
| Jobs outside the cluster | census-export |

## Planted weaknesses (8)

| # | ATG rule | Where | What was planted |
|---|---|---|---|
| 1 | API1 | `GET /appointments/{appointment_id}` | No owner check: any patient can open any appointment, notes included. |
| 2 | TS-06 | `GET /records/{record_id}/pdf` | The download link carries the session token in the query string. |
| 3 | API8-ROOT | `patient-service` | No runAsNonRoot: the container may run as root. |
| 4 | LT-02 | `web-gateway` | nginx runs without a tracing module, so the gateway sends no spans. |
| 5 | LT-01 | `GET /auth/introspect` | Consequence of the untraced gateway: nginx's session checks reach the auth service with no trace. |
| 6 | API5 | `GET /internal/census` | Internal reporting endpoint answers any pod without a credential. |
| 7 | TS-01 | `GET /internal/census` | The same endpoint returns 2xx to anonymous callers. |
| 8 | LT-01 | `GET /internal/census` | Called by an export script that sends no trace. |
