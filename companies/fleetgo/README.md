# FleetGo

Logistics (parcel delivery). Shippers create shipments and track them; dispatch staff manage drivers. Istio's ingress gateway has its own load balancer, and an ext-authz policy checks sessions.

| | |
|---|---|
| Language | go (`companies/runtime/go`) |
| Gateway | `ingress-gateway`, configured as istio |
| Login | bearer token |
| Public entry | `api.fleetgo.example`, TLS, Istio gateway with its own load balancer |
| Service mesh mTLS | STRICT |
| OpenAPI | 3.0.3 at `/openapi.yaml` |
| Outside APIs | none |
