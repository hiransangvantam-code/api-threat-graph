# FoodDash

Food delivery. Customers order from restaurants and pay; a dispatch service assigns riders. The cluster's nginx Ingress forwards to Istio's gateway.

| | |
|---|---|
| Language | node (`companies/runtime/node`) |
| Gateway | `mesh-gateway`, configured as istio |
| Login | bearer token |
| Public entry | `api.fooddash.example`, TLS |
| Service mesh mTLS | no |
| OpenAPI | 2.0 at `/swagger.json` |
| Outside APIs | none |
| Jobs outside the cluster | none |
