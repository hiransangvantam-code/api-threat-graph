# PayNow

## Planted weaknesses (6)

| # | ATG rule | Where | What was planted |
|---|---|---|---|
| 1 | API1 | `GET /wallets/{wallet_id}/statement` | No owner check: any customer can read any wallet's statement. |
| 2 | TS-08 | `POST /ledger/entries` | Wallet and transfer services post ledger entries with no credential, and the ledger accepts them from any pod. |
| 3 | TS-01 | `POST /ledger/entries` | The same ledger write succeeds without any credential. |
| 4 | API8-TAG | `wallet-service` | Deployed from the :latest image tag. |
| 5 | API10 | `transfer-service` (fx-rates) | Transfers use exchange rates from an outside API. |
| 6 | LT-04 | `POST /transfers` | One transfer in 25 fails with a server error. |
